# 版权、商标与下架请求流程

如果你认为仓库中的内容侵犯了你的著作权、商标权、肖像权、隐私权或其他权利，请通过可验证的方式联系维护者。

## 建议提交的信息

- 你的姓名、联系方式和权利身份；
- 受保护作品或权利的具体说明；
- 涉嫌侵权内容的文件路径、链接和定位信息；
- 你拥有权利或获授权代表的说明；
- 你认为构成侵权的事实和理由；
- 你希望采取的删除、替换、署名、链接或其他措施；
- 声明信息真实，并愿意承担相应责任的声明；
- 电子或手写签名。

## 处理方式

维护者收到有效通知后，可以：

- 请求补充材料；
- 暂时隐藏或移除争议内容；
- 替换素材或补充署名；
- 与提交者沟通授权方案；
- 在必要时将争议转交 GitHub 的官方流程处理。

## 隐私与安全

不要在公开 Issue 中发布身份证件、住址、私人电话、账号凭据、医疗信息或其他敏感资料。涉及隐私、安全或商业机密的材料应优先使用私密联系渠道。

## GitHub 官方流程

涉及 GitHub 托管内容时，也可以使用 GitHub 提供的版权或敏感数据官方流程。若需要 DMCA 通知，应按 GitHub 当前要求提交完整信息。此流程由 GitHub 处理，不由本插件项目替代。
