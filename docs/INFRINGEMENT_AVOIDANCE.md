# 侵权规避与内容审查清单

本清单用于发布前自检，不能替代专业法律意见，也不能保证生成结果不侵权。

## 1. 素材来源审查

- 图片、视频、音频、字体、贴图、音乐、模型和 Skill 是否有明确来源？
- 是否允许复制、修改、再分发、商业使用和二次训练？
- 是否保留许可证、作者、版本、链接和授权证据？
- 是否包含他人 Logo、水印、平台界面、角色、歌词、配音或影视截图？
- 是否包含未授权的真人脸、声音、身份证件、车牌、住址或未成年人信息？
- 如果无法确认权利，是否能用自制素材替换？

## 2. 生成内容审查

- 是否复制了可识别的角色、演员、艺人、主播、运动员或公众人物的外观和声音？
- 是否复制了原作的关键镜头、独特构图、经典台词或标志性视觉元素？
- 是否生成真实品牌、虚假代言、虚构认证、假新闻或误导性的公共信息？
- 是否涉及暴力、色情、未成年人、仇恨、骚扰、诈骗、违法指导或危险行为？
- 是否需要在画面、音频、说明或元数据中标识 AI 生成/深度合成？

## 3. 商业发布审查

- 广告文案、性能数据、价格、资质和用户评价是否真实可核验？
- 是否拥有音乐、字体、配音、演员、场地、道具和商标的商用授权？
- 是否遵守模型提供商、API、ComfyUI 生态和目标平台的商业使用规则？
- 是否完成目标国家/地区的隐私、广告、消费者保护、版权和 AI 披露审查？
- 是否为可能的投诉、下架、更正和证据保全准备好流程？

## 4. 不建议的判断方式

以下说法本身不能作为免责依据：

- “只改了颜色/名字/比例”；
- “模型自己生成的，所以没有版权问题”；
- “网上公开可见，所以可以商用”；
- “没有标注水印，所以不是侵权”；
- “免费使用就不会侵犯权利”；
- “仅供学习”；
- “生成后没有直接复制”。

## 5. 发现争议时

1. 暂停生成、分发和商业使用；
2. 保留提示词、素材来源、授权和发布记录；
3. 不要删除可能用于核实的必要证据，除非法律或平台要求；
4. 评估替换、下架、更正、署名或取得授权；
5. 必要时咨询有资质的法律专业人士。
