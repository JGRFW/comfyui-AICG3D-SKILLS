# 首尾帧生图提示词

使用顺序固定为：

- `<Picture 1>` = 首帧
- `<Picture 2>` = 尾帧

如果用户没有明确说明，默认按此顺序解释。

## 内部处理

1. 分别识别首帧和尾帧的主体、动作、构图、光线和背景。
2. 找出必须保持的身份、服装、道具和空间锚点。
3. 找出需要连续变化的动作、表情、位置、光线或环境状态。
4. 在内部处理无法同时保留的细节，以首尾帧锚定和自然连续变化为优先。
5. 把中间阶段直接写进同一个提示词，不另列建议。

## 最终输出

只输出一个完整自然段，直接描述从 `<Picture 1>` 到 `<Picture 2>` 的连续画面生成要求。自然段中应包含身份与服装锁定、动作和位置过渡、构图与背景稳定、光线与材质变化。

不要输出：

- 标题、编号或 Markdown；
- 首尾帧判断；
- 连续性分析；
- 冲突或不确定项；
- 中间帧建议标题；
- 负面约束或规避说明；
- MiniMax H3 视频字段、分析、备注或操作建议。

提示词必须可直接复制粘贴到生图模型。
