# 视频反推提示词

把用户提供的实际视频片段作为时间性证据。重点是还原结构、动作因果、镜头和声音关系，不是逐帧复制原片。

## 工作步骤

1. 识别视频数量和 `<Video N>` 映射；多个视频分别记录。
2. 按时间顺序拆分镜头，记录每个镜头的景别、主体、动作、空间、镜头运动和转场。
3. 描述动作因果链：前一动作如何导致下一动作，人物和道具的位置如何变化。
4. 记录可见文字、对白、环境声、动作声和音乐线索；听不清或看不清的内容直接省略，不在最终结果中说明。
5. 将可复用的结构、节奏和镜头机制与不可复制的原片内容分开。
6. 涉及真人身份、品牌、影视角色、音乐、台词、Logo 或独特镜头时，改为中性替代，不复制权利敏感内容。
7. 用户指定输出语言时严格使用该语言；对白和画面文字保留原语言。

## 最终输出

严格只输出以下六个字段，按顺序排列：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

不要输出：

- 六段式之外的镜头时间线或表格；
- 反推摘要、结构拆解、H3 参考用法、合规说明或规避项；
- 分析过程、备注、质量检查或操作建议；
- 引导语、结尾说明或任何第六段之后的文字。

结果必须可以直接复制粘贴给 MiniMax H3。
