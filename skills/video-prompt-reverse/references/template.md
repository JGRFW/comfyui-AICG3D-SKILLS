# 视频反推输出模板

```text
subject_definitions:
[定义 <Subject N>、<Picture N>、<Video N>、<Audio N> 的用途]

summary:
[一段话概括目标视频内容、动作目标和最终结果]

retention_analysis:
[每个参考标签一行，写明保留或迁移的具体视觉、动作、镜头、节奏或声音属性]

detailed_description:
[按时间顺序写景别、构图、主体动作、表情、镜头运动、空间、道具、光线和转场]

overall_soundscape:
[环境声、动作声、人声与静默变化]

non_diegetic_music:
[音乐信息或 N/A]
```
