# 数字人演唱提示词执行规则

本文件用于 `audio-prompt-reverse`。目标是产出可直接粘贴到 11 号 MiniMax H3 数字人工作流的六段式提示词，让人物按锁定歌曲音轨完成逐字演唱，并拥有像 MV 一样有节奏、有变化的多角度镜头设计。

## 一、输入关系

- 单人模式：`<Picture 1>` 是数字人主体、服装、背景、光线和构图来源。
- 双人对唱：男子图绑定男声 `<Subject N>`，女子图绑定女声 `<Subject N>`，场景图绑定共同 `<Subject N>`；不得把所有歌词都交给同一个人。声部优先用 wav2vec2 男女声分类模型判断，再用音色聚类交叉确认；模型不可用或仍不确定时，禁止猜测男女切换。
- 歌词转写：上传多长音频就分析多长音频，输出完整歌词和全部时间码；“视频时长”只控制 H3 单段生成参数，不裁剪歌词识别结果。
- 锁定歌曲音轨：由 11 号数字人工作流从 AICG3D 资源库接入，音频内容、人声、伴奏、节奏、停顿、音色和时长全部复用。
- 歌词时间线：节点识别或用户校正后的最终歌词。时间是目标提示词中的真实演唱时间段。

不要在最终提示词中输出 `<Audio N>` 标签。数字人节点运行时会把它们删除，导致 `retention_analysis` 出现残缺行。

## 二、六段式结构

### subject_definitions

写清：

- 单人：`<Subject 1>` 是 `<Picture 1>` 中的人物，身份为歌手 `(S1)`；
- 双人：男声 `<Subject N>` 来自男子图，女声 `<Subject N>` 来自女子图，共同场景 `<Subject N>` 来自场景图；
- 保留每人的脸型、五官、发型、服装、配饰、体型和稳定空间位置；
- 男声时间段画面中有且只有男子，女声时间段画面中有且只有女子；另一人完全在画外，不出现第二张脸、第二张嘴或第二套口型；
- 不穷举与演唱无关的细节。

### summary

使用关系标记：

```text
[reference generation + digital human audio reuse]
```

单人说明人物保持参考身份并完成逐字演唱。双人说明男女声使用交替单人镜头，每个时间段只出现当前歌手一个人，另一人完全在画外。

### retention_analysis

单人至少两行；双人还要分别保留男子图、女子图和场景图：

```text
<Picture 1>: fully_preserved - 人物身份、脸型、发型、服装、配饰、体型和构图保持稳定。
锁定歌曲音轨: fully_copy - 原歌曲、人声、伴奏、节奏、停顿、音色和时长作为完整最终音轨原样复用。
```

### detailed_description

必须以 `[Shot 1]` 开头，并包含：

1. 写实或与参考图一致的视觉风格；
2. 每个镜头的景别、位置、机位运动、构图和切镜动作；
3. 每张人物图和场景图的身份、服装、空间位置与屏幕方向连续；
4. 锁定歌曲音轨完整复用；
5. 当前歌手的嘴唇、下颌、舌头、呼吸、眼神、头部和肩颈与歌声同步；对唱镜头中有且只有当前歌手一人；
6. 按真实时间码逐段写歌词和时间表。

时间表格式：

```text
[Shot 2] 在 00:03.560 处，句首硬切到女声单人镜头；男声完全在画外。
00:03.560-00:07.120, <Subject 2> (S2) sings:
<d>[Mandarin singing] 第二句真实歌词</d>
```

要求：

- `[Shot 1]` 不带切点时间码；从 `[Shot 2]` 起，每个镜号后写 `在 MM:SS.mmm 处`，切点必须严格递增。
- 时间范围来自歌词识别结果，不得重排。
- `<d>` 内只放语言标签和逐字歌词。
- 保留原语言、标点和文字，不自行补句号或改写。
- 口型与每个时间段对应，长音、转音、换气和重音写成可见的面部与呼吸变化。
- 不把全部歌词堆在开头，也不写“随后继续演唱”这类笼统说明。

### overall_soundscape

写 `N/A`。完整歌曲音轨已经由数字人模式锁定，不重复描述背景音乐。

### non_diegetic_music

写 `N/A`。不创建第二条音乐或替代音轨。

## 三、MV 运镜设计

不要全片只使用一个变焦、缓慢推进或固定机位。三个以上歌词段时，至少使用三种真正不同的镜头语法：

- **横移揭示**：低机位广角沿场景横移，借现场前景视差从环境落到歌手。
- **低机位跟拍**：沿肩线做侧向 Truck，人物与背景产生不同速度。
- **三分之四 Dolly**：机位实际向前或向后移动，不用焦距突变代替。
- **交替单人反打**：男女声切换时直切男声单人镜头或女声单人镜头，未演唱者不进入画面。
- **30° 小弧线**：只做受控小角度环绕，避免完整绕脸导致身份漂移。
- **手持跟随**：跟随重心、肩颈和手势，动作有目的，不做全程晃动。
- **Crane/Pedestal**：高机位下降或在结尾升起，改变空间层次。
- **结尾拉远**：Crane Up + Dolly Out 从当前歌手单人近景拉回共享场景，画面仍只保留当前歌手。

每个镜头只承担一个主要机位动作。切镜可以借鉴 MV 的硬切、动作匹配切、擦镜切和重音直切，但必须满足：

- 切点放在下一句歌词起唱、换气或明确重音处，不能切在咬字中间。
- 起唱时保留演唱者完整嘴部和可读面部，不用大侧脸、强遮挡或极端俯拍遮住口型。
- 同一个人跨镜头保持脸型、发型、服装和配饰一致。
- 每个对唱歌词镜头只能出现当前歌手一人；另一位歌手完全在画外，不生成其脸、嘴、身体或口型。
- 不为了炫技连续堆叠多个运镜术语；一个镜头一个明确目的。

## 四、稳定与防错

- 人物身份、脸型、发型、服装、配饰和场景关系全程不变。
- 允许有创意的机位变化，但不做无依据的瞬移、换景、跳轴或身份漂移。
- 头肩和手指只做与节拍一致的自然律动，不重复机械摆手。
- 不添加新的歌词、对白、旁白、人声、音效或音乐。
- 不添加字幕、歌词文字、Logo、水印、麦克风、乐器或额外人物，除非用户明确要求。
- 不出现口型延迟、提前张嘴、闭嘴发声、张口无声、五官漂移或面部拉伸。

## 五、输出检查

返回前确认：

1. 六个字段完整且顺序正确；
2. 没有 `<Audio N>` 标签；
3. `retention_analysis` 同时有 `<Picture 1>: fully_preserved` 和“锁定歌曲音轨: fully_copy”；
4. `detailed_description` 从 `[Shot 1]` 开始；
5. 每个真实时间段都有对应 `<d>` 歌词；
6. 歌词逐字一致，时间码没有倒序；
7. 三个以上歌词段时至少有三种不同镜头，不是全程只变焦；
8. 第六段之后没有说明或建议。
