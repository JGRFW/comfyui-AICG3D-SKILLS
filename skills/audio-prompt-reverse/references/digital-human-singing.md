# 数字人演唱提示词执行规则

本文件用于 `audio-prompt-reverse`。目标是产出可直接粘贴到 11 号 MiniMax H3 数字人工作流的六段式提示词，让人物按锁定歌曲音轨完成逐字演唱、口型同步和稳定表演。

## 一、输入关系

- `<Picture 1>`：数字人主体、服装、背景、光线和构图来源。
- 锁定歌曲音轨：由 11 号数字人工作流从 AICG3D 资源库接入，音频内容、人声、伴奏、节奏、停顿、音色和时长全部复用。
- 歌词时间线：节点识别或用户校正后的最终歌词。时间是目标提示词中的真实演唱时间段。

不要在最终提示词中输出 `<Audio N>` 标签。数字人节点运行时会把它们删除，导致 `retention_analysis` 出现残缺行。

## 二、六段式结构

### subject_definitions

写清：

- `<Subject 1>` 是 `<Picture 1>` 中的人物；
- 人物是目标视频中的歌手 `(S1)`；
- 保留脸型、五官、发型、服装、配饰、体型、背景和主要构图；
- 不穷举与演唱无关的细节。

### summary

使用关系标记：

```text
[reference generation + digital human audio reuse]
```

用一句话说明：人物保持 `<Picture 1>` 的身份和外观，并按照锁定歌曲音轨完成逐字演唱和口型同步。

### retention_analysis

必须有两行：

```text
<Picture 1>: fully_preserved - 人物身份、脸型、发型、服装、配饰、体型和构图保持稳定。
锁定歌曲音轨: fully_copy - 原歌曲、人声、伴奏、节奏、停顿、音色和时长作为完整最终音轨原样复用。
```

### detailed_description

必须以 `[Shot 1]` 开头，并包含：

1. 写实或与参考图一致的视觉风格；
2. 数字人的景别、位置、镜头和构图；
3. `<Picture 1>` 身份与服装保持稳定；
4. 锁定歌曲音轨完整复用；
5. 嘴唇、下颌、舌头、呼吸、眼神、头部和肩颈与歌声同步；
6. 按真实时间码逐段写歌词和时间表。

时间表格式：

```text
00:00.000-00:03.560, <Subject 1> (S1) sings:
<d>[Mandarin singing] 第一句真实歌词</d>

00:03.560-00:07.120, <Subject 1> (S1) sings:
<d>[Mandarin singing] 第二句真实歌词</d>
```

要求：

- 时间范围来自歌词识别结果，不得重排。
- `<d>` 内只放语言标签和逐字歌词。
- 保留原语言、标点和文字，不自行补句号或改写。
- 口型与每个时间段对应，长音、转音、换气和重音写成可见的面部与呼吸变化。
- 不把全部歌词堆在开头，也不写“随后继续演唱”这类笼统说明。

### overall_soundscape

写 `N/A`。完整歌曲音轨已经由数字人模式锁定，不重复描述背景音乐。

### non_diegetic_music

写 `N/A`。不创建第二条音乐或替代音轨。

## 三、稳定与防错

- 人物身份、脸型、发型、服装、配饰和构图全程不变。
- 镜头稳定，允许极轻微推进，不做无依据的大幅运镜。
- 头肩和手指只做与节拍一致的小幅自然律动。
- 不添加新的歌词、对白、旁白、人声、音效或音乐。
- 不添加字幕、歌词文字、Logo、水印、麦克风、乐器或额外人物，除非用户明确要求。
- 不出现口型延迟、提前张嘴、闭嘴发声、张口无声、五官漂移或面部拉伸。

## 四、输出检查

返回前确认：

1. 六个字段完整且顺序正确；
2. 没有 `<Audio N>` 标签；
3. `retention_analysis` 同时有 `<Picture 1>: fully_preserved` 和“锁定歌曲音轨: fully_copy”；
4. `detailed_description` 从 `[Shot 1]` 开始；
5. 每个真实时间段都有对应 `<d>` 歌词；
6. 歌词逐字一致，时间码没有倒序；
7. 第六段之后没有说明或建议。
