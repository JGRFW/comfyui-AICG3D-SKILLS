# 文生图提示词

在内部补全画面设计，最终只输出一段可直接复制粘贴的图片提示词。

## 内部补全

1. 明确主体数量、类型、外观、服装、动作和表情。
2. 建立场景、时间、天气和空间层次。
3. 确定景别、视角、构图和主体位置。
4. 明确主光方向、色温、明暗层次、阴影、反射和色彩关系。
5. 统一材质、媒介、画风和后期质感。
6. 用户没有指定画风时，选择与内容匹配且可执行的视觉方向。

## 最终输出

只输出一个完整自然段。

不要输出：

- 标题、编号或 Markdown；
- 正向提示词、主提示词等字段名；
- 结构化拆解；
- 负面约束或规避说明；
- MiniMax H3 视频字段、镜头时间线、声音或对白；
- 分析、备注、操作建议或“以下是”等引导语。

输出语言服从插件设置。提示词必须可直接复制粘贴到生图模型。
