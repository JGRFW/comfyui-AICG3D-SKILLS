# 单人/多人替换完整测试与提速手册

## 一、先理解耗时来源

白模节点主要耗时：

1. SAM3 视频跟踪。
2. SAM3D Body 逐帧动作推理。
3. 表情提取、平滑和白模渲染。
4. 媒体加载器读取超高分辨率视频。

后面的 MiniMax H3 采样主要耗时：

1. 25 步扩散采样。
2. 输出分辨率和视频时长。
3. 文本编码器和视频 VAE 的加载与编码。

## 二、通用测试原则

不要直接从完整视频开始跑。固定按三级验收：

```text
第一级：白模只跑 3~5 秒，确认人物数量、动作、颜色、背景。
第二级：H3 只替换 3~5 秒，确认身份、口型、背景和动作。
第三级：全套通过后，再跑最终时长和最终输出分辨率。
```

## 三、单人替换流程

### 素材

```text
Picture 1：要替换的唯一人物，优先使用单人正面半身图。
Picture 2：只有换背景时才放入场景图；不换背景时不要引用。
Video 1：原视频或白模动作视频。
```

### 白模节点参数

只换人、保留原场景：

```text
最大人物数 = 1
检测阈值 = 0.50~0.60
检测间隔 = 1
长边像素 = 512（测试）/ 736（最终）
推理批大小 = 64；显存不足降到 32/16/8
启用MoGe = 关
渲染模式 = mesh
着色器 = default
启用表情 = 开
启用平滑 = 开
保留原始音频 = 开
保留原视频场景 = 开
绿色背景 = 关
逐人锁定颜色 = 关
```

换人并换背景：

```text
最大人物数 = 1
保留原视频场景 = 关
绿色背景 = 开
逐人锁定颜色 = 开
人物颜色排序 = 左到右
人物颜色强度 = 0.30~0.45
```

### 已选视频上下文

```text
分段方式 = 按时间切分
每段秒数 = 3 或 5
替换总时长 = 3 或 5（测试）
原片参考强度 = 0.15~0.25（彩色白模）
锁脸 = 先关；身份弱时再开
连续方式 = 运动上下文（连贯稳定）
```

### H3 Loader

```text
主模型 = MiniMax/minimax_h3_hybrid_fl2va_ref2va_b25-49-int8.safetensors
LoRA 1 = h3_character_swap_pro4500_1000.safetensors
LoRA 1 强度 = 1.0~1.2
其它 LoRA = none（先不要叠加加速 LoRA）
采样器 = er_sde
调度器 = simple
步数 = 25
denoise = 1.0
```

### 单人提示词结构

```text
<Picture 1> 是唯一人物身份来源。
<Subject 1> 只替换蓝色 ID 或原视频中的目标人物。
<Video 1> 提供动作、口型、说话时序、镜头、时长和原音轨。
如果换背景，再加入 <Picture 2> 作为背景。
最终人物使用参考图中的真实肤色、头发和服装。
```

### 单人验收标准

```text
1. 白模中只有目标人物。
2. 目标人物动作与原视频一致。
3. H3 输出人物脸型、发型和服装与 Picture 1 一致。
4. 不换背景时背景和原视频一致；换背景时场景与 Picture 2 一致。
5. 口型和说话时序没有转移到错误人物。
6. 最终画面没有白模材质、蓝色、绿色或黑色背景。
```

## 四、多人替换流程

### 素材

```text
Picture 1：第一个人物，默认蓝色 ID / Subject 1。
Picture 2：第二个人物，默认红色 ID / Subject 2。
Picture 3：场景图，只有换背景时使用。
```

更多人物按“人物图在前、场景图最后”继续排列。

### 白模节点参数

```text
最大人物数 = 实际替换人数（双人填 2）
检测阈值 = 0.55~0.65
检测间隔 = 1
长边像素 = 512（测试）/ 736（最终）
推理批大小 = 64；显存不足降到 32/16/8
启用MoGe = 关
渲染模式 = mesh
着色器 = default
启用表情 = 开
启用平滑 = 开
保留原始音频 = 开
逐人锁定颜色 = 开
人物颜色排序 = 左到右
人物颜色强度 = 0.40~0.50
```

换背景：

```text
保留原视频场景 = 关
绿色背景 = 开
```

保留原场景：

```text
保留原视频场景 = 开
绿色背景 = 关
```

### 已选视频上下文

```text
替换总时长 = 3~5（测试）
原片参考强度 = 0.15~0.25
锁脸 = 关
连续方式 = 运动上下文（连贯稳定）
```

多人任务不要依赖单脸锁脸，因为旧锁脸逻辑只适合确认一个人脸；多人优先依靠颜色 ID 和人物参考图。

### H3 采样

第一轮测试保持：

```text
LoRA 1 = h3_character_swap_pro4500_1000.safetensors
LoRA 1 强度 = 1.0~1.2
其它 LoRA = none
步数 = 25
denoise = 1.0
```

不要在第一次测试时同时叠加 DMAD、风格 LoRA 或其它加速 LoRA，否则无法判断是谁导致身份漂移。

### 多人验收标准

```text
1. 蓝色和红色人物数量正确，没有路人或重复跟踪。
2. 人物穿插、遮挡和换位时颜色 ID 不互换。
3. 蓝人只换 Picture 1，红人只换 Picture 2。
4. 两个人物的动作和口型跟随各自颜色 ID，不串换。
5. 背景替换正确，最终没有绿色和白模颜色。
```

## 五、调试参数表

| 现象 | 主要调整 | 次要调整 |
|---|---|---|
| 白模多出人物 | 最大人物数=实际人数；检测阈值提高到 0.60~0.70 | 检测间隔保持 1 |
| 漏掉真实人物 | 检测阈值降低到 0.40~0.50 | 使用更清晰的动作视频 |
| 人物身份没有被替换 | 确认人物替换 LoRA 已加载；强度 1.0~1.2 | 参考图裁成单人正面半身 |
| 只替换了一个人 | 降低原片参考强度到 0.10~0.18 | 检查红色 ID 是否稳定存在 |
| 动作和原视频不一致 | 原片参考强度提高到 0.25~0.35 | 降低彩色 ID 强度 |
| 蓝色/红色进入成片 | 人物颜色强度降到 0.25~0.40 | 关闭逐人颜色做单人物测试 |
| 背景是蓝色 | 关闭“保留原视频场景”，打开绿色背景，换非蓝场景图 | 原场景是蓝色时无法靠提示词去除 |
| 背景没有换 | 确认 Picture 3 是场景图且没有人物 | 检查 Picture 编号绑定 |
| 人物边缘有灰影 | 使用当前版本的颜色边缘羽化逻辑 | 不要使用过大的颜色强度 |
| 白模速度慢 | 长边像素=512；检测间隔=2 仅测试用 | 媒体解码长边设为 736 |
| H3 速度慢 | 先只跑 3~5 秒，输出 480P，25 步 | 通过验收后再测试 8 步加速方案 |

## 六、推荐提速档位

### 一级预览速度

```text
白模长边像素 = 448~512
白模检测间隔 = 2
媒体解码长边 = 512
替换总时长 = 3
H3 输出 = 480P
H3 步数 = 25（保证身份基线）
```

### 二级标准速度

```text
白模长边像素 = 736
白模检测间隔 = 1
媒体解码长边 = 736
替换总时长 = 5
H3 输出 = 480P
H3 步数 = 25
```

### 三级最终质量

```text
白模长边像素 = 736~1024
白模检测间隔 = 1
媒体解码长边 = 0（自动）
替换总时长 = 实际需求
H3 输出 = 480P 或 720P
H3 步数 = 25
```

## 七、最终判断顺序

```text
先看白模
→ 再看 H3 的 5 秒预览
→ 再看最终 25 步成片
→ 最后才考虑加速 LoRA 和更高分辨率
```

只要白模阶段的人物数量、颜色 ID 或动作不正确，就不要进入 H3 全量生成。
