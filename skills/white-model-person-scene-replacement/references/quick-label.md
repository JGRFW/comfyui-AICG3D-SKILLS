# 3D白模人物场景替换速用卡

> 最终推荐：白模只做辅助。单人直连源视频：Character Swap=1.0、Turbo=1.0、er_sde/beta、8步、source=1.0。多人物必须一个人一遍顺序替换。只换背景用“静态换景·人物像素锁定”。

```text
【3D白模人物场景替换｜速用卡】

一、先选任务
[ ] 只换人物，保留原场景
    → 保留原视频场景=开，绿色背景=关
    → 人物图在前，不引用场景图

[ ] 换人物 + 换背景
    → 保留原视频场景=关，绿色背景=开
    → 单人：Picture 1=人物，Picture 2=场景
    → 双人：Picture 1/2=人物，Picture 3=场景
    → 最终禁止绿色和白模颜色

[ ] 只换背景
    → 优先原视频；人物身份、动作、口型、镜头全保留
    → 场景图整体替换背景

二、人物颜色 ID
蓝色=Subject 1（替换1）
红色=Subject 2（替换2）
绿色=Subject 3
品红=Subject 4
青色=Subject 5
黄色=Subject 6

人物穿插、遮挡、移动、左右换位：按颜色 ID 锁人，不按左右临时换人。

三、背景规则
换背景：场景图负责建筑、地面、树木、光线、色彩、空间。
保原景：不定义场景 Subject，不引用场景图。
只换景：不改变原人物身份、服装、动作、口型、镜头和音轨。
最终成片禁止：绿色背景、绿幕边缘、白模材质、黑底、蓝红色块、三视图排版。

四、口型规则
无真实台词：不写 <d>。
Skill 规则不是台词；无真实台词时最终 <d> 数量必须为 0。
无逐人台词时间线：不指定某一侧全程说话；每个人物继承原视频对应位置或颜色 ID 的口型、停顿、倾听和静默。
有真实台词：保留语言、标点、时间码和正确 Subject。

五、推荐参数
双人替换：最大人物数=2；原片参考强度=0.10~0.20
人物替换 LoRA=h3_character_swap_pro4500_1000，强度=1.0~1.2
逐人颜色强度=0.40~0.55；采样步数>=25
彩色白模不能被当最终外观照抄；4步预览不是最终结果。

六、输出格式
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:

七、硬检查
1. 不用的 Picture 不定义、不引用。
2. 颜色 ID 不互换，左右口型不串换。
3. 换背景时绿色和白模色必须消失。
4. 不换背景时不引用场景图。
5. 不添加新人物，不改变原人物数量。
6. 动作、口型、镜头、时长以 Video 1 为准。
7. 只输出六段式正文。
```
