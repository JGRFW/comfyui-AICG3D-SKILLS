## 一、 经典拳法与打击武学

### 1. 形意拳（五行十二形 · 直线整劲穿透）
* **核心动作**：
  * **劈拳**：三体式立身，长线斜向下劈砸肩胸，前脚踩进半步，沉劲开路。
  * **钻拳**：后拳沿胸腹中线向上螺旋钻顶，拳尖直刺咽喉下颌。
  * **崩拳**：前后拳交替直线短促前崩，寸劲直击心口，双脚箭步连续跟进（半步崩拳）。
  * **炮拳**：一手上架开劈打，另一拳横向平直猛炮砸击侧肋腰腹。
  * **横拳**：双拳贴身螺旋横拨，破械横撞胸腔。
  * **十二形**：虎形双扑、马形冲撞、鹞形绕身、燕形贴地钻击、龙形起伏、猴形闪展。

### 2. 八极拳（刚猛短促 · 寸劲硬炸 · 贴身短打）
* **核心动作**：
  * **铁山靠**：全身重量与前冲力聚于肩背，如铁壁正面撞入，踩碎地面。
  * **顶肘 / 盘肘 / 反背肘**：肘尖短促爆发前撞，六大开·顶，破防重创。
  * **阎王三点手**：左冲、右崩、左直连珠快拳打乱防线，紧接一记跺地顶心肘贯穿心口。
  * **撑锤·十字整劲**：前拳轰出同时后手猛拉对拉，整劲前后贯穿爆发。
  * **六大开（顶/抱/单/提/胯/缠）**：全面破开一切格挡架势。

### 3. 咏春拳（小念头正统十二式 · 守中用中 · 短桥寸劲）
* **核心动作**：
  * **二字钳羊马 / 摊手**：二字马稳扎，前臂沿中线上扬外摊化开直拳。
  * **伏手 / 膀手 / 窒手**：掌心向下压桥、肘部外拱弧形顶开摆拳、前下方短促压截对方发力点。
  * **日字冲拳**：拳眼朝上立拳归中，双拳左右交替沿中线机括连射。
  * **标指**：双指并拢沿中线平直穿刺咽喉心口，指尖先到。
  * **捆手 / 拍手 / 低踢**：双臂螺旋缠臂封控，拍开防线零间隔打入，下盘隐蔽低踢脚踝胫骨。

### 4. 八卦掌（游身连环掌 · 趟泥走圈 · 避正打斜）
* **核心动作**：
  * **白蛇吐信**：沿圆步侧身滑走，单掌贴腰平直穿刺心口咽喉。
  * **鹞子穿林**：趟泥步穿插绕至敌后，单掌自腋下、肋下钻出穿打。
  * **乌龙摆尾 / 回身劈掌**：180°大转身借离心力，掌根横扫侧肋或垂直劈砸脊柱中线。
  * **狮子抱球 / 穿身绕掌**：双掌环抱撑架格挡，贴身螺旋环绕穿插点打胸腹空档。

### 5. 太极拳（以柔克刚 · 借力打力 · 刚柔互济）
* **核心动作**：
  * **掤捋挤按**：前臂撑出如球弹开来力 $\rightarrow$ 双手顺力后拉引化 $\rightarrow$ 合力向前挤入 $\rightarrow$ 双掌推出贯穿。
  * **采手引偏 / 挒开**：抓住手腕向下拽偏重心，横向翻转拧开来臂。
  * **云手 / 揽雀尾 / 搬拦捶**：双手画圆连绵化解，反手重拳轰击太阳穴。

### 6. 泰拳（Muay Thai 八肢武艺 · 硬骨三层压制）
* **核心动作**：
  * **刺拳 / 直重拳 / 横勾拳**：高护架控距，后拳中线贯穿，横勾拳砸下颌。
  * **中段扫踢 / 低位扫腿 / 蹬推踢**：支撑脚拧胯，胫骨如斧横砍肋部肝区，脚掌直线顶推阻断突进。
  * **横斩肘 / 上挑肘**：近身缠抱，大臂水平横摆切割眉骨鼻梁，斜向上挑击下颌。
  * **正顶膝 / 斜切膝 / 飞冲膝**：双手扣颈泰式颈夹，膝盖垂直顶撞胸腹或斜切浮肋，腾空飞膝俯冲爆头。

### 7. 散打（综合搏击 · 远踢近打贴身摔）
* **核心动作**：
  * **转体鞭拳 / 转身后蹬**：转体 180° 鞭拳横扫，转身脚跟向后直线蹬出。
  * **接腿推摔 / 挟颈过胯摔**：接住对方踢击小腿向前推摔，挟住颈部转身过胯翻摔。
  * **截线侧踢 / 快线鞭腿**：以腿截腿阻断攻势，快出快收连续轰击。

### 8. 空手道（刚劲直突 · 一击必杀 · 寸止定格）
* **核心动作**：
  * **正拳突**：拳从腰间冲出，拧腰转胯整劲直轰。
  * **手刀劈**：掌缘如刀自上而下劈砍颈肩。
  * **寸止定格**：全力出击 $\rightarrow$ 命中瞬间定格 0.1 秒 $\rightarrow$ 力量全部释放收招。

## 二、 腿法、地趟与柔道摔投

### 1. 少林旋风地堂腿（贴地滚 · 低空扫 · 腾空旋）
* **核心动作**：
  * **贴地平扫腿 / 仆步勾撩**：身体侧伏贴地，单腿贴地横扫脚踝小腿；仆步极低挑勾脚踝。
  * **侧滚截蹬 / 伏地后绊**：侧滚避上盘攻击，滚身脚掌截蹬膝弯；伏身让拳后腿横绊脚后跟。
  * **滚身锁膝**：贴地滚至腿侧，双腿如夹钳缠住膝关节旋身带倒。
  * **按地腾空旋风脚**：双掌猛按地面借力，身体自贴地瞬间腾空水平旋转，双腿如旋风刀轮横扫。
  * **鲤鱼打挺撞腿**：卧地腰背猛弹如鲤鱼打挺，双腿并拢直线撞入胸腹心窝。

### 2. 巴西战舞（Capoeira · 弹跳空翻 · 倒置出腿）
* **核心动作**：
  * **基达达后撤 / 罗达转圈**：双脚弹性滑步回旋，以自身为圆心环形周旋。
  * **安哥拉侧旋踢 / 马尔特洛翻转踢**：单脚支撑旋转 360° 水平扫腰；单手触地侧身半翻转斜挑下颌。
  * **阿乌空翻 / 阿乌梅利亚空中连踢**：双手撑地完整侧空翻；空翻中连续两段斜踢（先肋后颈）。
  * **库拉多低位扫踢 / 雷桑戈回旋肘**：极低位贴地横扫脚踝；侧身小幅旋转回旋肘切面门。

### 3. 十二路谭腿（拳三腿七 · 12种腿法全覆盖）
* **12 路绝技**：弹（弹射）、踩（千斤坠踩踏）、截（以腿截腿）、蹬（攻城锤直蹬）、劈（大斧劈落）、挂（挑挂化解）、撩（由下挑裆）、扫（秋风扫叶）、鞭（转腰鞭抽）、踹（侧门封死）、膝（贴身暴击）、摆（钟摆连环）。

### 4. 三十六路腿法（武当北派腿法百科全书）
* **核心体系**：直摆性（正踢/斜踢/侧踢/里合/外摆） $\rightarrow$ 目标型（窝心/破膝/破心/通肋） $\rightarrow$ 屈伸性（弹腿/边腿/反腿/下劈/尖子脚） $\rightarrow$ 腾空性（旋风腿/腾空外摆莲/二起脚） $\rightarrow$ 高级复合（低高边腿/玄功腿五腿合一）。

### 5. 柔道（Judo · 67 式投技与地面寝技）
* **手技 / 腰技 / 足技**：背负投（经典过肩摔）、一本背负投、体落、大腰、扫腰、内股（内侧挑摔）、大外刈（大弧线外侧扫腿）、出足扫（脚踝横扫）。
* **捨身技**：巴投（仰身倒地脚蹬腹部翻摔过头顶）、裏投（后仰过背摔）。
* **地面固技与绞杀**：袈裟固、上四方固、十字固（反关节拉直肘部）、裸绞（背后绞杀颈动脉）、腕缄。

### 6. 三十六路擒拿手（抓/拧/折/别/压/缠/绊/摔）
* **经典杀招**：抓腕反扭、别臂扒肩、折肘卸肩、压掌卷腕、剪臂挫肘、倒背金人、缠臂锁肩、高祖斩蛇（下潜锁膝踝）。

## 三、 兵器体系与高级身法

### 1. 九套正统剑法
* **武当太乙玄门剑**：道家圆转、步踏九宫、慢蓄快发（青龙出海、云卷长空、回锋点星）。
* **独孤九剑**：无招胜有招，专寻破绽，细锐星芒单点穿刺（总诀式、破剑式、破气式、寻瑕刺隙）。
* **华山基础剑法**：干净锐利、长线直刺（白虹贯日、直刺咽喉、天马行空）。
* **玉女十九剑**：轻盈缠绕、多层柔光锁械（缠剑锁械、碎星点刺、叠剑合围）。
* **峨眉白猿二十四剑**：猿形灵动、短促脆劲突袭（金蛇出洞、纵步翻刺、跃步穿心）。
* **青龙剑 32 式**：大开大合大弧线横斩（平地起雷、穿林刺喉、乌龙绞柱）。
* **峨眉子午剑**：短距极速爆发、点穴锁喉（子午穿心、闪步突刺、旋腕点目）。
* **武当六路 132 式总剑**：腾空与地躺全维度清场（滚身扫剑、翻身崩剑、锁喉横斩）。
* **杨式 55 式太极剑**：以柔化刚、连续光轨（三环套月、退步穿林）。

### 2. 正统死神长柄镰刀（写实无锁链）
* **核心动作**：低身平镰扫胫、横月平斩、升镰挑割、镰钩拉扯卸械、蓄力满月重斩、腾空落月斩。单柄长金属镰刀，冷银浅灰金属刃光。

### 3. 雷电梦想一心太刀术（神性太刀居合）
* **核心动作**：胸口拔刀、居合快斩、瞬身落雷、无想横斩、满愿梦想一刀。深紫/纯紫电弧收束入刀，空间撕裂细纹。

### 4. 绯雪樱灼流单太刀术（双形态单刀）
* **核心动作**：唯一迅刀「灼霜」，折樱上挑、白鸟回薙、枯霜居合突、时停反刃弹、千霜环身斩、归刃漫天雪。

### 5. 高级轻功体系（25 核心式 · 借力非瞬移）
* **核心动作**：借力树梢/瓦片/水面/绳索折身换向（凌波微步、踏雪无痕、移星换斗、断崖折月、天外归鸿）。禁止无理由悬浮。

### 6. 修仙高级剑招体系（仙侠御剑与剑阵）
* **核心动作**：御剑飞刺、剑气横空、万剑归宗、层叠剑墙、虚空裂斩、陨星坠剑。
