# 人物场景替换 Skill 压缩规则

## 任务定义

输入是原视频、人物参考图和可选场景图。输出必须是 MiniMax H3 Ref2VA 六段式提示词。用户只指定当前需要替换的对象，Skill 不擅自扩大替换范围。

## 四种模式

| 模式 | 用户要做什么 | 素材 | LoRA / 锁脸 |
|---|---|---|---|
| A. 单人替换 | 只替换一个人 | 1 张人物图 + 视频 | 可开单人物换人 LoRA；可考虑锁脸 |
| B. 多人替换 | 同时替换两个或更多人物 | 每人一张人物图 + 视频 | 关闭单人物换人 LoRA；关闭锁脸 |
| C. 人物 + 场景 | 替换人物并替换背景 | 人物图 + 纯场景图 + 视频 | 单人时可开 LoRA；多人时关闭 |
| D. 单独场景 | 只替换背景，人物保持原样 | 1 张纯场景图 + 视频 | 关闭换人 LoRA；关闭锁脸 |

也支持单人 + 场景、多人 + 场景、只替换其中一部分人物等组合。

## 六段固定顺序

1. `subject_definitions`
2. `summary`
3. `retention_analysis`
4. `detailed_description`
5. `overall_soundscape`
6. `non_diegetic_music`

## 素材职责

- `<Video 1>`：待编辑目标视频，负责运动、时间轴、构图、机位、口型、对白和原音轨。
- 每个人物对应一个独立 `<Picture N>` 和 `<Subject N>`。
- 场景图对应独立 `<Subject N>`；只有使用它时才定义。
- 未参与本次替换的素材不定义、不引用。

## 关系标记

- `<Video 1>`：`fully_preserved`
- 被替换的人物：`attribute_transfer`
- 被替换的背景：`attribute_transfer` 或 `fully_preserved`
- 原音轨复用：`fully_copy` 或 `partially_copy`

## 硬规则

1. 先判断 A/B/C/D 模式，再写提示词。
2. 只定义用户本次要替换的人物或场景。
3. 多人替换时，每个人物都有独立的身份映射。
4. 多人替换时关闭 `h3_character_swap_pro4500_1000`。
5. 单独场景替换时，人物身份、数量、动作和音轨全部保留。
6. 没有对应素材时不引用 `<Picture N>`。
7. 不把素材说明列表直接当成生成提示词。
8. 不写否定式指导、工作流术语或参考图分栏排版。
9. 没有用户给出的确切台词时，不输出 `<d>` 对白，不把任务说明或问题写成台词。
10. 用户提供台词时逐字保留原语言和原标点；复用原音轨时只描述口型和说话动作。
11. 最终只输出六段式正文。
