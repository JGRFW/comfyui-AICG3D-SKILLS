# 人物场景替换运行前检查表

## 模式

- [ ] 单人替换：只定义一个人物。
- [ ] 多人替换：每个人物独立 `<Subject N>`，关闭单人物换人 LoRA 和锁脸。
- [ ] 人物 + 场景：人物与背景分别定义；多人时关闭换人 LoRA。
- [ ] 单独场景：只定义场景；人物、动作、对白和音轨全部保留。
- [ ] 没有使用到的素材没有被定义或引用。

## 素材顺序

- [ ] 每张人物图对应明确的具体人物。
- [ ] 场景图只包含背景环境。
- [ ] `<Video 1>` 是要编辑的原视频。
- [ ] 提示词里的 `<Picture N>` 编号与资源库顺序一致。

## 节点设置

- [ ] 主模型为 MiniMax H3 Ref2VA 或 FL2VA/REF2VA 融合模型。
- [ ] 模式为 Ref2VA 全能参考。
- [ ] 涉及人物替换时开启换人模式。
- [ ] 单人替换可用 `h3_character_swap_pro4500_1000`。
- [ ] 多人替换关闭 `h3_character_swap_pro4500_1000`。
- [ ] 多人替换关闭锁脸；单独场景也关闭锁脸。
- [ ] 原片参考强度从 0.15 起步，按身份或动作效果调整。
- [ ] 采样器 `er_sde`，调度器 `simple`，步数 25，降噪 1.0。

## 提示词

- [ ] 六段字段齐全且顺序正确。
- [ ] `<Video 1>` 使用 fully_preserved。
- [ ] 本次被替换的人物或背景使用 attribute_transfer。
- [ ] 没有确切台词时没有生成任何 `<d>` 对白。
- [ ] 有台词时保留原语言、原标点和语气；复用原音轨时只描述口型同步。
- [ ] 没有否定式指导、七段式栏名、工作流术语或参考图排版描述。

## 日志确认

正确进入人物替换通路时，日志应包含：

```text
[AICG3D][换人] 共 ... 段
采样起点=空潜变量
预编码 ... 段画面参考
参考[video:..., image:...]
```

如果日志出现 `Selected Video Prepare` 和 `Segment Refine`，说明当前走的是原片二次重绘通路，人物替换模式没有真正生效。
